# FireLine
Nepredvidljivost požarov in njihova hitra širitev zahtevata napredne metode za njihovo obvladovanje in spremljanje, zato želimo razviti rešitev, s katerimi bi drastično zmanjšali širitev gozdnih požarov s pametnim načrtovanjem požarnih pregrad in tako razbremenili delo gasilcev in zmanjšali katastrofalne posledice.
